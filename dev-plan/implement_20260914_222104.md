# implement_20260914_222104.md

작성 일시: `2026-09-14 22:21:04 KST`

이 문서는 현재 로그인된 일반 Chrome의 네이버 SmartEditor에 Naver Content OS 앱만으로 완성 원고와 이미지 3장 이상을 입력하고, 임시저장 후 재열기 검증까지 한 번의 작업으로 끝내기 위한 개발 범위를 고정한다.

## 개발 목적

- 사용자가 앱에서 한 번 요청하면 원고 생성부터 네이버 임시저장 검증까지 외부 CUA·수동 복사·수동 파일 선택 없이 완료한다.
- 현재 Chrome 탭을 대상으로 하되, 공개 발행은 절대 수행하지 않는다.
- 성공 판정은 버튼 클릭이나 토스트가 아니라 저장본 재열기와 제목·본문·이미지 일치 검증으로 확정한다.

## 개발 범위

- 현재 Chrome과 설치된 확장 사이의 SmartEditor 명령 브리지
- Draft 버전에 귀속되는 이미지 자산과 삽입 위치 manifest
- 제목·본문·이미지·태그 입력 및 임시저장 job state machine
- 중복 실행 방지, 단계별 재시도·재개, 저장본 재열기 검증
- 로컬 fake 테스트와 실제 계정 1턴 인수 테스트

## 제외 범위

- 공개 발행 자동화
- 네이버 ID·비밀번호·쿠키 저장 또는 복사
- 이용 권리가 확인되지 않은 외부 이미지의 자동 사용
- 기존 전용 CDP Chrome 경로 제거

## 권장 구조

1. 웹앱이 Local Core에 `current_chrome_extension` 전송 방식으로 publish job을 생성한다.
2. 설치된 확장 background가 해당 job을 long-poll하고 현재 활성 네이버 편집기 탭을 확인한다.
3. content script가 제목·본문을 입력하고 Local Core의 일회성 asset URL에서 이미지 blob을 받아 지정 위치에 삽입한다.
4. 각 이미지가 네이버 업로드 URL로 전환된 것을 확인한 뒤 임시저장을 실행한다.
5. 별도 검증 탭에서 같은 임시저장 글을 재열고 제목, 정규화 본문 hash, 이미지 수와 원격 URL을 비교한다.
6. 모든 검증이 통과한 경우에만 job을 `verified_draft_saved`로 종료한다.

기존 전용 CDP Chrome은 fallback 및 개발용으로 유지한다. 현재 Chrome 제어가 필수인 기본 경로는 확장 브리지로 전환한다.

## 결정 기록

- 기본 전송 방식: `current_chrome_extension`
- 보조 전송 방식: 기존 `dedicated_chrome_cdp`
- 기본 성공 상태: 저장 버튼 클릭이 아닌 `verified_draft_saved`
- 최소 콘텐츠 기준: 본문 3,000자, 원격 저장 이미지 3장
- 사용자 조작 기준: 네이버 로그인과 최초 확장 설치를 제외하고 작성 중 수동 조작 0회
- 복구 기준: 실패 시 같은 job과 같은 네이버 임시글을 재개하고 새 임시글을 중복 생성하지 않음

- 사용자가 앱에서 한 번 실행한다.
