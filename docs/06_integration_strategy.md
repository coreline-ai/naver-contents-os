# 06. 통합 전략: 키워드 분석 + 콘텐츠 제작 엔진 결합

## 핵심 판단
두 프로젝트는 경쟁 관계가 아니라 **기능 보완 관계**.

| 항목 | keyword-tool | blog-automation |
|---|---:|---:|
| 연관키워드 | ★★★★★ | ★★★★☆ |
| 검색량 | ★★★★★ | ★★★★☆ |
| 문서수 | ★★★★★ | ★★★★☆ |
| 트렌드 저장 | ★★★★☆ | ★★☆☆☆ |
| 경쟁사 모니터링 | ★★★★☆ | ★☆☆☆☆ |
| 글 구조 생성 | ★☆☆☆☆ | ★★★★★ |
| 스크린샷 입력 | ☆☆☆☆☆ | ★★★★★ |
| 원고 작성 | ☆☆☆☆☆ | ★★★★★ |
| 이미지 배치 | ☆☆☆☆☆ | ★★★★★ |
| 썸네일 | ☆☆☆☆☆ | ★★★★★ |
| SmartEditor | ☆☆☆☆☆ | ★★★★★ |

### 통합의 목적
- 키워드 분석: `keyword-tool` 중심
- API 수집: SearchAd/Trend는 공통 엔진화
- 콘텐츠 제작: `blog-automation` 중심
- 최종: 브라우저 확장 + 로컬 백엔드 + SmartEditor 임시저장

## 권장 아키텍처(텍스트화)
`네이버 검색어 트렌드/검색량` + `SERP 분석` + `Opportunity` 를 통해
`콘텐츠 기획(시리즈/검색형/홈피드형/쇼핑형)`으로 확장.

## 모듈 재사용/재설계 지침
### 그대로 가져가도 되는 부분
- `automation/editor.py`
- `config/selectors.py`
- `core/content_parser.py`
- `core/thread_expander.py`
- `core/thumbnail_html.py`
- `core/image_handler.py`

### 교체/개선 권장
- 검색 API 인증 처리(개발자센터 → API HUB)
- 자동 로그인 로직 제거
- Desktop GUI 제거(웹 UI 또는 확장 기반으로 일원화)
- 고정 템플릿 제거(유형별 템플릿)
- Unsplash 중심 전략 → 스크린샷/정보이미지 우선
- JSON/파일 기반 상태 → DB 기반 Job state 도입

## 향후 연동 시나리오
네이버 확장 검색창/사이드바에서 키워드 클릭 후:
- 연관 키워드 + 경쟁 분석
- 15개 시리즈 구성 제안
- 원고 생성 → SEO/근거 스코어 표시
- SmartEditor 임시저장
- 사용자 최종 검수 후 발행

확장성 및 안정성을 위해 매우 적합한 결합 패턴.
