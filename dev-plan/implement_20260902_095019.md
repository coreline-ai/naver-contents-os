## 개발 목적

현재 구현된 Naver Content OS의 기능 범위를 유지하면서 회귀 방지, 오류 처리, API·UI 계약 정합성, 검증 자동화, 문서 정확성을 보강한다.

신규 사용자 기능은 추가하지 않는다. 키워드 분석, 기존 Opportunity Score v1, 15편 플랜, 구조/AI 초안, Blog Inspector, SmartEditor 임시저장 전용 흐름의 현재 동작만 안정화한다. 자동 공개 발행은 계속 금지하며 최종 발행은 항상 사람이 결정한다.

## 개발 범위

- Python 3.12·Node 24 기준 non-live 검증 환경과 baseline을 확보한다.
- Provider·Gateway·Analyze·Opportunity Score의 기존 응답 계약과 결측/오류 강하를 회귀 검증한다.
- Draft REST API·Ollama/OpenAI 호환 LLM·Publisher의 기존 오류 분류와 상태 보존을 안정화한다.
- Extension의 기존 분석·SERP 첨부·Blog Inspector·구조/AI 초안 흐름에서 stale state와 잘못된 안내를 제거한다.
- Secret 없는 non-live 검증을 CI에 고정한다.
- HANDOFF·README·품질 문서를 실제 코드와 테스트 결과에 맞춘다.

- 기존 API route와 TypeScript 공개 타입을 깨지 않는다.
- 기본 LLM은 local이며 `openai_compat`는 사용자 명시 설정에서만 사용한다.
- SmartEditor는 Health Check 전체 통과 후 임시저장까지만 수행한다.
- CI는 Secret이 필요 없는 non-live 검증만 실행한다.
- 재현되지 않은 추측성 수정은 하지 않는다. 테스트 또는 코드 계약으로 확인된 결함만 수정한다.
