## 개발 목적

**V2 — Codex OAuth Proxy 기반 외부 LLM Provider 연결.**
사용자의 ChatGPT 구독(Codex CLI OAuth, `~/.codex/auth.json` — 로컬에 인증 존재 확인됨, codex-cli 0.145.0)을 로컬 OpenAI 호환 프록시로 노출하는 오픈소스를 활용해, API 키 없이 GPT 계열 모델로 블로그 초안을 생성할 수 있게 한다. V1의 `LLMProvider` 인터페이스는 유지하고 Provider 구현체만 추가한다.

## 문서 기반 제약 사항

- **Secret 경계 유지**: `auth.json`·access token·`OPENAI_COMPAT_API_KEY`는 절대 로그·DB·fixture에 남기지 않는다. 프록시는 127.0.0.1 bind만 허용.
- **외부 전송 고지**: `LLM_PROVIDER=openai_compat` 설정 시 초안 프롬프트(키워드·질문·플랜 제목)가 OpenAI 백엔드로 전송된다. 기본값은 `local`(Ollama) 유지, 외부 전송은 사용자의 명시적 설정으로만 활성화 — docs/11 규칙 7과의 정합성을 문서에 명시.
- **비공식 경로 고지**: 구독 OAuth 프록시는 OpenAI 비공식(ChatMock 고지: "not affiliated with OpenAI"). 사용자 본인 계정·자기 책임 사용임을 docs에 명시하고, 백엔드 변경으로 깨질 수 있으므로 오류를 명확히 분류해 안내한다.
- **인터페이스 불변**: `LLMProvider.generate(prompt, *, system)` 계약과 `DraftService`의 스켈레톤 fallback(`--no-llm`) 경로는 변경하지 않는다.
- 프록시 미기동/토큰 만료는 크래시가 아니라 분류된 `LLMError`(unreachable/auth)로 강하하고 재로그인·기동 방법을 메시지에 포함한다.

- `chatgpt.com/backend-api/codex/*`는 비공식 백엔드 — OpenAI 측 변경 시 프록시가 깨질 수 있음. 오류 분류로 감지하고, 참조 저장소 업데이트를 추적한다.
- thkdog 프록시는 토큰 자동 갱신이 없어 장기 미사용 시 401 발생 가능 → codex CLI 사용(또는 재로그인)으로 auth.json 갱신 필요, 안내 메시지로 대응.
- 프록시 선택지 중 ChatMock은 별도 로그인 상태를 가짐 — 사용자가 혼용하면 어느 인증이 쓰이는지 혼동 가능 → docs에 1개 경로만 권장.
- 후속(V2.1 후보): 스트리밍 표시, 초안 길이 미달 시 이어쓰기 1회, 사이드패널에서 초안 생성 트리거 UI.
