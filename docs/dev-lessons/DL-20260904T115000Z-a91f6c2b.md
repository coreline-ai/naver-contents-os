# LLM 완성 원고는 분량·문단 수만으로 성공 판정하지 않는다

## 적용 범위와 비적용 조건

LLM이 생성한 한국어 블로그 원고를 Draft로 저장하기 전 품질 Gate와 로컬 모델 실사용 인수에 적용한다. 사용자가 직접 입력하고 저장한 원고에는 자동 폐기 기준으로 적용하지 않는다.

## 관측 사실과 영향

qwen3:4b는 2,500자 요청에서 본문 대신 영문 사고 과정을 2,794자로 출력했고, 당시 구조 점수는 이를 100점으로 통과시켰다. qwen3:8b는 한국어 본문을 만들었지만 동일 문장·문단과 장문 키워드를 반복했고 키워드가 18회 들어간 2,235자 원고가 85점으로 저장됐다. qwen2.5:14b Q3도 아이의 주민등록번호를 저장하거나 노출하라는 위험 조언이 있는 원고를 90점으로 통과시켰다. 글자 수와 문단 수만 맞아도 읽을 수 없거나 위험한 원고가 최근 Draft에 노출되는 QA escape가 발생했다.


## 근본 원인·기여 요인·근거

기존 validator가 길이, 제목, 문단, placeholder 중심으로만 평가해 응답 언어, 사고 과정 노출, 정확히 같은 문장의 반복, 키워드 도배를 성공 조건에서 제외한 것이 직접 원인이다. 작은 로컬 모델의 프롬프트 이행을 단위 테스트 mock만으로 검증했고 실제 생성 본문을 읽는 인수 절차가 없었던 점이 기여했다. draft #7과 #12의 저장 본문 및 실제 compose 응답으로 반복 재현했다.

## 해결과 예방 control

Ollama는 사고 모드를 끄고 제목과 서로 다른 섹션 배열만 허용하는 JSON schema로 생성한다. 저장 전 한국어 비율, 영문·국문 메타 문구, placeholder, 키워드 횟수와 구성 단어 범위, 동일 문장 다양성, 주민등록번호·계좌번호·비밀번호 등 민감 식별정보 조언을 critical 검사한다. 내용은 정상이나 분량만 짧을 때만 기존 원고를 유지한 소규모 보강을 허용하고, 반복·메타·언어·민감정보 실패는 전체 재작성 후에도 통과하지 못하면 저장하지 않는다. 미검토 검색 메타데이터는 자동 승인 FactPack으로 승격하거나 사실 근거로 주입하지 않는다.

## 검증

`tests/unit/test_article_quality.py`에 영문 사고 과정, 반복 문장, 장문 키워드 검사를 추가했다. `tests/integration/test_drafts_service.py`에서 정상 통과, 재작성 통과, 짧은 정상 원고 보강, 보정 실패 시 Draft 미생성을 확인한다. 로컬 모델 변경은 단순 status 확인으로 끝내지 않고 실제 2,500자 compose 결과의 제목·본문·반복·근거 없는 사실을 사람이 읽어 확인한다.

## 발생 정보

2026-09-04 완성 글 자동 작성 개발의 실모델 QA에서 발견했다. 실패 원고는 공개 발행되지 않았고 검증 과정에서 생성된 qwen3 및 qwen2.5 Draft 7건은 보관 처리해 기본 최근 목록에서 제외했다.

## 검토와 예외

새 모델이나 프롬프트 버전을 도입하면 같은 실제 compose 인수를 다시 수행한다. 특정 모델의 점수만 근거로 품질 규칙을 완화하거나, 재검사 실패 원고를 경고와 함께 저장하는 예외는 허용하지 않는다. 사실 정확성은 이 Gate가 보장하지 않으므로 최신 가격·운영시간·정책은 승인된 근거나 사용자 확인이 별도로 필요하다.
