## 개발 목적
- 기존 기능을 축소하지 않고, 앱 자체가 완성 원고·이미지를 네이버에 임시저장하고 재열기까지 검증하도록 한다.
- Ego Lite는 앱 화면 조작·관찰·검수에 사용한다. 에이전트가 네이버 편집기에 대신 입력한 결과를 앱 단독 성공으로 계산하지 않는다.
- 실제 1회 저장 인수를 먼저 완료한 뒤 작성·이미지 UX, 페이지 수집, 최신 키워드, 데모·종합 검수 순으로 진행한다.

## 개발 범위
- P0: Ego Lite 실행 환경·확장 호환성·동일 브라우저 연결 확인, 잘못된 worker의 작업 수령 방지, 실제 앱 단독 1회 저장 인수.
- P1: 한 화면의 작성·이미지 검수·임시저장·재개 흐름.
- P2: 현재 페이지 분석 자료의 웹 연결, 검증 가능한 최신·인기 키워드 데이터 연결.
- P3: 운영 환경과 분리된 정식 데모, 기능 보존·실서비스·접근성 인수 및 문서 동기화.

## 실행 역할과 흐름

```text
사용자 / Ego 검수
  → Ego 안의 Naver Content OS 웹 화면에서 주제·실행 선택
  → Local Core: 기존 AI 원고 생성·품질 검사·버전/이미지 고정
  → 같은 Ego의 Naver Content OS 확장: 앱 명령 수령
  → 확장 내부 chrome.debugger: 네이버 입력·이미지 업로드·임시저장
  → 확장: 저장본 재열기 및 원고/이미지/태그 대조
  → Local Core: 검증 통과 시에만 verified_draft_saved
  → 웹 화면: 결과·실패 단계·복구 행동 표시
```

`chrome.debugger`는 기존 확장 API 이름이다. Google Chrome으로 전환한다는 뜻이 아니다. Ego에서 해당 API·파일 업로드·재열기 지원 여부는 Phase 1에서 실제 확인한다.
