## 개발 목적
키워드 입력부터 완성 블로그 글 생성과 네이버 SmartEditor 임시저장까지를 초보자도 이해할 수 있는 단일 흐름으로 재설계한다.

## 개발 범위
우선순위를 다음으로 고정한다.

1. 실제 LLM 준비 상태를 판정하고 연결되지 않으면 템플릿을 완성 글처럼 노출하지 않는다.
2. 키워드·작성 목적·사용자 메모로 완성된 글을 생성하고 규칙 기반 자동 검사와 실패 유형별 재작성·분량 보강을 수행한다.
3. 사이드패널 기본 화면을 `주제 입력 → 완성 글 만들기 → 초안 확인 → 네이버 임시저장`으로 단순화한다.
4. SmartEditor 설정은 블로그 ID를 1회 저장하고 상태·실패 단계를 사용자 용어로 안내한다.
5. `이미지`를 글 생성 모드에서 제외하고 `참고 사진 찾기`로 이름과 실행 시점을 바꿘 재사용 권리 확인 전에는 다운로드·업로드하지 않는다.
6. 기존 상세 분석은 제거하지 않고 `상세 도구`에 숨겨 고급 사용자만 선택적으로 열게 한다.
