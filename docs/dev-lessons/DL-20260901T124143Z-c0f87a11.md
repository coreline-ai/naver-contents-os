# SearchAd keywordstool은 공백 포함 hint 키워드를 4xx로 거부한다

## 적용 범위와 비적용 조건

SearchAd /keywordstool 호출부 전체. 다른 SearchAd API의 파라미터 규칙은 별도 확인 필요.

## 관측 사실과 영향

키워드 '애드포스트 승인'(공백 포함)으로 hintKeywords를 보내면 4xx 응답으로 request 오류가 발생했다. 스모크 테스트는 무공백 키워드만 사용해 통과했기 때문에 실서버 E2E에서야 드러났다.

## 근본 원인·기여 요인·근거

keywordstool의 hintKeywords는 공백 없는 형태만 허용하며 응답 relKeyword도 무공백으로 반환된다. 사용자 입력 그대로 전달한 것이 원인.

## 해결과 예방 control

클라이언트에서 hint 전송 전 공백을 제거한다(providers/searchad/client.py). 키워드 동일성 비교는 공백 무시(casefold+replace) 규칙 사용.

## 검증

tests/unit/test_searchad_client.py::test_hint_keyword_spaces_are_stripped 회귀 테스트 통과. 실서버 E2E에서 '애드포스트 승인' 분석 성공(searchad ok).

## 발생 정보

2026-09-01 Phase 3 실서버 E2E에서 발견. 영향: 해당 키워드 분석의 SearchAd 블록 결측(즉시 수정).

## 검토와 예외

다중 hint(쉼표 구분) 지원을 추가할 때 이 규칙을 각 항목에 적용해야 한다.
