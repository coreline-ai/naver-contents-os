## 문서 기반 제약 사항

- API Secret은 Extension에 두지 않는다. `127.0.0.1` Local Core만 Secret을 사용한다 (docs/11 Secret 경계).
- FastAPI는 `127.0.0.1` bind, CORS는 허용 Extension Origin만, Extension↔Core 간 `LOCAL_CORE_TOKEN` 사용.
- Secret·Authorization 헤더·전체 API 응답을 로그에 남기지 않는다 (키 앞 4자리도 금지, 설정 여부만 기록).
- API 한도는 코드에 하드코딩하지 않고 설정으로 분리한다. 유효 한도 = `min(일, 월, 콘솔 설정, RPS)`.
- Search Trend `ratio`는 상대값이다. 절대 검색량(SearchAd)과 혼합 표기하지 않고 출처·수집 시각을 함께 저장한다.
- SmartEditor는 Selector Health Check 전체 통과 시에만 입력을 시작하고, 임시저장까지만 수행한다.
- 정규화 모델은 `source`, `collected_at`, `raw_schema_version`을 필수로 가진다 (docs/12).
