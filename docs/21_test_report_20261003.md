### 지역 API 실패 원인

대상: `/search/v1/local`. 별도 진단 1회에서도 HTTP 401과 다음 응답이 확인됐다.

> 요청한 API는 이 Application에서 활성화되어 있지 않습니다.

**조치:** 현재 키가 연결된 네이버 API Application에서 지역 검색 API 활성화/이용 설정을 확인한 뒤 지역 smoke를 재실행한다. 현재 계정 설정을 확인하거나 변경하지는 않았다. 다른 API는 같은 키로 통과했으므로 전체 키가 잘못됐다고 단정하지 않는다. Local Core 연결 토큰이나 네이버 블로그 로그인으로 해결되는 오류도 아니다.
